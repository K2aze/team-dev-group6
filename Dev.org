* Issue
** Cannot write on disk
- ErrorException: =tempnam(): file created in the system's temporary directory=
- Fix:
  On terminal:
  #+begin_src bash
    chown -R www-data:www-data storage bootstrap/cache
    chmod -R 775 storage bootstrap/cache
  #+end_src
- Reason: The project was created by the root user via =composer create laravel\[sth]=, so the files it created are also owned by root.

** Splash white screen after fix cannot write on disk
- Fix:
  On =src/vite.config.*=
  #+begin_src typescript
    server: {
        host: '0.0.0.0',
        port: 5173,
        strictPort: true,
        hmr: {
            host: 'localhost',
        },
    },
  #+end_src
