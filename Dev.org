* Getting started
After cloning the repository:
#+begin_src bash
  cp .env /.env                 # skip if .env already exists
  cp src/.env.example src/.env  # skip if src/.env already exists
  docker compose up --build -d
  docker compose exec app bash  # or: sh

  # Inside the app container
  composer install
  php artisan key:generate
#+end_src

* Known issues
** Cannot write to disk
- Error: =tempnam(): file created in the system's temporary directory=
- Cause: the project was created by =root= (via =composer create-project=), so its files are owned by root.
- Fix (inside the =app= container):
  #+begin_src bash
    chown -R www-data:www-data storage bootstrap/cache
    chmod -R 775 storage bootstrap/cache
  #+end_src

** White screen after fixing the disk error
- Fix:update =src/vite.config.*=:
  #+begin_src typescript
    server: {
        host: '0.0.0.0',
        port: 5173,
        strictPort: true,
        hmr: {
            host: 'localhost',
        },
    },
  #+end_src
